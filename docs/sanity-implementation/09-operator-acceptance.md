# Langkah 9 — Operator Acceptance Test

## Skenario wajib

- Mengubah judul dan gambar hero.
- Menonaktifkan slide hero.
- Menemukan slot Profil Perusahaan.
- Menemukan Beranda → Tentang Kami → Gambar latar.
- Membuat dan publish artikel.
- Membuat dokumen kemitraan dan legalitas.
- Menyembunyikan dokumen tanpa menghapus.
- Menambah Komisaris, Direksi, dan Tim/Divisi.
- Membuat divisi baru.
- Menggunakan posisi Lainnya.
- Mengubah alamat, email, dan telepon.

## Kriteria lulus

- Operator menyelesaikan skenario tanpa bantuan teknis.
- Pesan error dipahami.
- Operator tidak membuat duplikasi slot.
- Operator memahami Save Draft dan Publish.

## Catat hasil

Catat langkah membingungkan, label yang tidak dipahami, field yang hilang, error teknis, dan slot yang belum tersedia. Perbaiki UX berdasarkan hasil uji nyata.
